# 国际会议同声传译和发言队列控制

源提示词摘要：主持人维护代表发言队列、剩余时间、议题和临时插话；翻译团队维护多语种频道、术语和译员交接；字幕人员修正实时文本。队列调整保留版本，发言者切换后旧译文不会误绑定，并提供低延迟大屏模式和多会议厅隔离。

## 技术栈

Qwik City、TypeScript、Qwik UI、Qwik stores、TanStack Query、Modular Forms、Zod、qwik-speak。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62029`

## 可用流程

- 多会议厅独立维护代表、议题和发言队列，切换厅时数据互不影响。
- 发言人从排队、发言中、完成到跳过，支持临时插话和剩余时间调整。
- 多语种频道维护译员、术语和交接；交接后新增字幕归属新译员。
- 实时字幕支持版本化修正，低延迟模式只保留关键状态并停用非必要动态。
- 数据保存在浏览器 localStorage，刷新后继续保留。

## 并发与版本账

- 发言队列、字幕草稿、译员在岗记录共用**按厅版本账**（每厅一个单调递增的 `version`），所有写入都携带依据版本 `baseVersion`。
- 两位主持人（两个标签页）同时改同一厅时：**先写入的保留**，后到的写入因 `baseVersion` 落后被拒绝落账，进入**待合并**并列出字段级差异（账上当前值 / 本次提交值），不会覆盖先到内容。可由主持人显式「以当前版本为据重写」或「放弃」。
- 发言人切换、译员交接完成或队列顺序变化时，厅内**上下文纪元** +1，所有未确认字幕草稿自动**失效并重归属**到当前发言人与当前在岗译员，确认发布前可看到原归属记录。
- 写入失败（可用页头「模拟存储故障」开关演示）的操作会保留在**待办**里，按「厅 + 操作编号」重试（已落账的操作编号自动幂等跳过），每 4 秒自动重试，刷新或重开页面后继续。
